# Budget Tracker (Python)

콘솔 기반 가계부/지출 관리 프로그램입니다. 처음부터 클래스(`BudgetTracker`) 기반으로 설계했습니다.

## 기능

- 지출 내역 추가 (입력값 검증: 지출 종류를 카드/현금 등 정해진 목록 중에서만 선택 가능)
- 지출 내역 조회
- 총 지출 합계 확인
- 카드 vs 현금 카테고리별 합계 확인
- 지출 내역 삭제
- JSON 파일로 저장/불러오기 → 프로그램을 종료해도 기록이 유지됨

## 실행 방법

```bash
python budjet.py
```

실행하면 메뉴가 표시되고, 번호를 입력해 각 기능을 사용할 수 있습니다.

## 사용 예시

```
1. 지출 추가
2. 지출 목록 보기
3. 총 지출 확인
4. 카테고리별 합계 보기
5. 지출 삭제
6. 종료

원하는 작업을 선택하세요:
```

## 개발 과정

처음부터 `BudgetTracker` 클래스로 설계하여 지출 데이터와 관련 기능을 하나의 객체로 관리했습니다. 이후 카드/현금 카테고리별 합계 기능과, JSON 파일 기반 저장/불러오기 기능을 추가해 프로그램 종료 후에도 데이터가 남도록 개선했습니다.

## 사용 기술

- Python 3
- `json` 표준 라이브러리 (데이터 저장/불러오기)
